The state convergence method offers an elegant approach to designing control gains for nth-order teleoperation systems, modeled in state space, to achieve bilateral control. This involves solving 3n + 1 equations, derived by treating the master-slave error as an autonomous system and then prescribing desired dynamic behaviors for both the slave and error systems. The resulting controller effectively synchronizes master and slave motion while allowing adjustable force reflection to the operator. However, a key limitation of the state convergence method is its reliance on precise model parameters. Parametric uncertainties can degrade controller performance. To overcome this, we propose enhancing the existing state convergence architecture by incorporating an extended state observer. This observer serves a dual purpose: it compensates for modeling inaccuracies by treating them as disturbances, and it provides estimates of both master and slave system states. These estimated states are then utilized to construct the bilateral controller, which is designed using the established state convergence methodology. This integration necessitates solving an additional 2n + 2 design equations to determine the observer gains. Validation of this enhanced state convergence architecture is conducted through simulations and semi-real-time experiments within a MATLAB/Simulink environment, using a single degree-of-freedom teleoperation system.

Bilateral teleoperation systems enable humans to execute tasks remotely using robotic devices. An operator initiates a task by controlling a local master robotic system. The master's trajectory data is then sent via a communication channel to a distant location, where a slave robotic system performs the designated task. Concurrently, the slave system relays environmental information back to the master, keeping the operator informed of remote events. This two-way information exchange between local and remote sites is crucial for successful task completion. However, this bilateral connection presents significant design challenges, primarily due to factors such as communication time delays, inherent system uncertainties, and limitations in bandwidth. Addressing these issues is essential for developing robust and effective teleoperation systems.

The control gains are determined by solving 3n + 1 design equations. These equations arise from two conditions: first, transforming the slave-master error into an autonomous system, and second, imposing desired dynamic behaviors on the slave and error systems. This model-based technique is suitable for linear teleoperation systems with small, constant communication channel time delays. To mitigate the state convergence scheme's dependence on model parameters, this study proposes using disturbance observers. These observers, specifically extended state observers, estimate uncertainties in the master and slave systems by treating them as disturbances. The choice of extended state observers is based on the assumption of slowly varying disturbances. The estimated states are then used to formulate a bilateral control law, designed according to the state convergence method, which also ensures the stability of the closed-loop teleoperation system. This proposed scheme is validated using MATLAB/Simulink simulations on a single degree-of-freedom nonlinear time-delayed teleoperation system. Previous research has utilized linear disturbance observers for teleoperation systems in oblique coordinates and modal spaces, and nonlinear disturbance observers have also been reported. However, a disturbance observer-based state convergence scheme has not been previously discussed in the literature, motivating this study. This enhancement improves the state convergence architecture by extending its operation to nonlinear systems and by estimating master and slave system states for use in bilateral control laws.

This paper introduces an improved state convergence architecture for bilateral teleoperation systems. The enhancement involves integrating disturbance observers to estimate uncertainties within the master and slave systems, treating these uncertainties as disturbances. Subsequently, the state convergence control laws are updated using these estimates. The method of state convergence is then applied to ensure the closed-loop stability of the teleoperation system. The proposed approach was validated through simulations and semi-real-time experiments conducted in MATLAB/Simulink, utilizing a single degree-of-freedom nonlinear time-delayed teleoperation system. Future research will focus on developing and incorporating operator and environment estimation laws into this framework, specifically addressing time-varying communication channel delays.

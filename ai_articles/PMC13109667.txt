The state convergence methodology offers a refined approach for designing control gains in nth-order teleoperation systems, which are modeled in state space for bilateral control. This method involves solving 3n + 1 equations, derived by treating the master-slave error as an autonomous system and then prescribing the desired dynamic characteristics for both the slave and error systems. The resulting controller guarantees synchronized motion between the master and slave, alongside adjustable force feedback to the operator. However, the state convergence method's reliance on precise model parameters is a drawback, as parametric uncertainties can compromise controller performance. To overcome this, we introduce an extended state observer into the existing state convergence framework. This observer serves a dual purpose: it mitigates modeling inaccuracies by treating them as disturbances, and it estimates the states of both the master and slave systems. These estimated states are subsequently utilized to formulate a bilateral controller, designed according to the state convergence principles. This enhanced design necessitates solving an additional 2n + 2 equations to determine the observer gains. The efficacy of this proposed improvement to the state convergence architecture is demonstrated through simulations and semi-real-time experiments conducted on a single degree-of-freedom teleoperation system within the MATLAB/Simulink environment.

Robotic devices enable humans to execute tasks remotely through bilateral teleoperation systems. The human operator begins a task by controlling a master robotic system. The master's movement data is then sent via a communication channel to a distant slave robotic system, which carries out the task. As the slave system works, it sends environmental data back to the master, keeping the operator informed about remote events. This essential two-way information exchange between local and remote sites is crucial for task completion. However, this bilateral link presents design difficulties, including time delays, system uncertainties, and bandwidth limitations.
Time delay significantly impacts the stability of bilateral teleoperation systems, a problem widely studied. To counter this, passivity schemes, rooted in transmission line theory, have been developed. These control algorithms prevent destabilization by converting system variables into wave-variables for transmission across the communication channel.
Linear control theory informs the optimal tuning of wave-variable controllers.
Beyond passivity controllers, which can suffer from over-dissipation and require passivity observers to activate them when active energy is detected, other common methods for bilateral teleoperation systems exist. These include H-infinity control, adaptive control, fuzzy model-based control, sliding mode control, model-mediated control, disturbance observers, and various hybrid approaches. Passivity schemes are also integrated with neural networks to handle system uncertainties.
Bilateral teleoperation systems have recently utilized the prescribed performance method to ensure desired transient behavior. Another new approach for contact motion in these systems is state convergence.
State convergence is a method for bilateral teleoperation systems that models nth-order master and slave systems in state space, offering a systematic approach to establish communication. The control gains are determined by solving 3n + 1 design equations. These equations arise from two key steps: first, converting the slave-master error into an autonomous system, and second, enforcing the desired dynamic behavior on both the slave and error systems. This model-based approach is suitable for linear teleoperation systems with small, constant time delays. To reduce its dependence on precise model parameters, this research introduces disturbance observers, specifically extended state observers, to estimate uncertainties in the master and slave systems by treating them as disturbances. This particular choice of observer is based on the assumption that disturbances vary slowly.
The proposed scheme, which constructs the bilateral control law using estimated states and the state convergence method, ensures the stability of the closed-loop teleoperation system. This approach was validated through simulations in MATLAB/Simulink (R2014a) on a single degree-of-freedom, nonlinear, time-delayed teleoperation system. While linear disturbance observers have been applied in oblique coordinates and modal spaces, and nonlinear disturbance observers have also been documented, this specific integration is novel.
This research is motivated by the absence of disturbance observer-based state convergence schemes in existing literature. The proposed method improves the state convergence architecture by enabling its application to nonlinear systems and by providing estimates of master and slave system states for bilateral control laws.

This paper introduces an improved state convergence architecture for bilateral teleoperation systems. The enhancement involves utilizing disturbance observers to estimate uncertainties within both master and slave systems, treating these inaccuracies as disturbances. Subsequently, the state convergence control laws are adjusted using these estimates. The stability of the closed-loop teleoperation system is then confirmed through the state convergence methodology. The effectiveness of this approach was demonstrated through simulations and semi-real-time experiments conducted in MATLAB/Simulink, using a single-degree-of-freedom nonlinear teleoperation system with time delays. Future research will focus on incorporating operator and environment estimation laws into this framework, accounting for variable communication channel delays.
